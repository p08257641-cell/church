# Ephesus Gatherings Worldwide — Official Web Platform

A modern, high-performance web platform built for **Ephesus Gatherings Worldwide** (The Son Place, Mikaddo Plaza, Labone, Accra, Ghana & Global Worldwide Family), crafted with **Vite + React + TypeScript** and a bespoke semantic CSS design system (strictly zero Tailwind).

## Key Features & Highlights
- **Authentic Royal Navy & Sacred Gold Identity**: Features the official Ephesus Gatherings Worldwide logo (monogram mark + typographic logotype) with Ephesus Royal Navy (`#0B1F4A` / `#1346AF`), Brushed Gold (`#D4AF37`), crisp Sanctuary Alabaster light mode, and Midnight Navy dark mode (plus Auto day/night mode).
- **Zero Bloat & Instant Navigation**: High-speed Vite 6 SPA with clean modular custom CSS and instant page transitions.
- **Christ-Centred Hero & Live Timezone Engine**: Features authentic sanctuary photography paired with real-time GMT + visitor local-timezone countdown ticket and `.ics` calendar sync for Sunday 15:00 GMT (3:00 PM) services and midweek prayer watches.
- **Education & Training Unit**: Dedicated showcase of the 5 specialized schools (*Foundation School*, *School of Discipleship*, *School of the Word*, *School of the Prophets*, *School of Faith*).
- **Ephesus Outreach & Partnership Unit**: Highlights the mission that has reached over 5,500 people, visited schools, and distributed thousands of Bibles and scholarships.
- **Direct Paystack Giving Gateway**: Direct integration with official verified church Paystack links for Tithes, Offerings, Seeds, Seed to Prophet, and Partnership covenants.
- **Interactive Broadcast Sanctuary (`/online-service`)**: Live/on-demand broadcast stage paired with an interactive 4-tab companion console (auto-saved sermon notes + `.txt` export, live prayer desk, altar call, and one-tap invite) plus Mixlr audio stream.
- **Persistent Floating Media Player**: Listen to *By My Side (Live)* or explore messages like *SUACH HAGAH 3.0*, *Grace for Life*, and *The Crisis of the Galatians 2.0* in a floating drawer while exploring any page.
- **Complete 11-Route Experience**:
  - `/` — Home Showcase, Service Countdown, Education Unit, Vision, Events, Testimonies & Sanctuary Gallery
  - `/about` — Pastor's Welcome in 9 Languages, Story & Vision, 5 Training Schools, Interactive 12 Articles of Faith, Founder Bio, and Leadership Team
  - `/online-service` — Live Broadcast Stage, Mixlr Stream, Companion Console & Sermon/Worship Archive
  - `/events` — Sunday Services, Cross Over Service, ITFC Camp & Interactive Calendar with RSVP Modal
  - `/testimonies` — Searchable & Filterable Testimony Wall (Grid/List toggle, Full Reader Modal & Submission Form)
  - `/salvation` — Gospel Presentation, Interactive Line-by-Line Guided Salvation Prayer & Connection Form
  - `/daily-readings` — 1-Year / 10-Month / 9-Month Bible Plans, Streak Tracker, Proverbs Challenge & Book of the Month
  - `/give` — Official Paystack Gateways, Kingdom Stewardship Principles, Designation Selector & 5-Point Security Promise
  - `/join` — Interactive Member vs. Affiliate Path Selector & Pastoral Welcome Form
  - `/resources` — Ministry Ecosystem Hub with zero dead links (Mixlr, Podcasts, WhatsApp channel, volunteer teams)
  - `/contact` — Headquarters at The Son Place, Labone, Accra, Ghana, phone helpline (+233 20 194 4006), and Confidential Prayer Request Desk

## Getting Started

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```
