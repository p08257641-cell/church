# Ephesus Gatherings Worldwide — Reimagined Platform

A modern, high-performance multi-page web platform built for **Ephesus Gatherings Worldwide — Diaspora** (and Mother Church connection in Accra, Ghana), crafted with **Vite + React + TypeScript** and a bespoke semantic CSS design system (zero Tailwind).

## Key Improvements Over the Legacy Site
- **Restored Authentic Royal Navy & Sacred Gold Identity**: Replaces the flat monochrome grey override with Ephesus Royal Navy (`#0B1F4A` / `#1346AF`), Brushed Gold (`#D4AF37`), crisp Sanctuary Alabaster light mode, and Midnight Navy dark mode (plus Auto day/night mode).
- **Zero Bloat & Instant Navigation**: Replaces ~300KB WordPress + unused WooCommerce payloads per page with instant client-side SPA routing and clean modular CSS.
- **Christ-Centred Hero & Live Timezone Engine**: Replaces internal patch-note vector graphics with high-resolution ministry photography paired with a real-time GMT + visitor local-timezone countdown ticket and `.ics` calendar downloads.
- **Interactive Broadcast Sanctuary (`/online-service`)**: Live/on-demand broadcast stage paired with an interactive 4-tab companion console (auto-saved sermon notes + `.txt` export, live prayer desk, altar call, and one-tap invite).
- **Persistent Floating Media Player**: Listen to *By My Side (Live)* or watch *The Occupying Army* and *ITFC 2026* highlights in a floating drawer while exploring any page.
- **Complete 11-Route Experience**:
  - `/` — Home Showcase, Countdown Ticket, Timezone Schedule, Vision, Founder, Events, Testimonies & Lightbox Gallery
  - `/about` (`/welcome`) — Pastor's Welcome in 9 Languages, Story & Vision, Interactive 12 Articles of Faith, Founder Bio & *The Emergence Podcast*, and all 7 Diaspora Coordinators
  - `/online-service` — Live Broadcast Stage, Companion Console & Sermon/Worship Archive
  - `/events` — Spotlight (*Night with the King 2026*), Filterable Programme, Interactive Monthly Calendar & RSVP Modal
  - `/testimonies` — Searchable & Filterable Testimony Wall (Grid/List toggle, Read tracking, Full Reader Modal & Submission Form)
  - `/salvation` — Gospel Presentation, Interactive Line-by-Line Guided Salvation Prayer & New Believer Connection Form
  - `/daily-readings` — 1-Year / 10-Month / 9-Month Bible Plans, Streak Tracker, Proverbs Challenge, Book of the Month & Email Reminders
  - `/give` — Kingdom Stewardship Principles, Designation Selector, Launch Alert & 5-Point Giving Security Promise
  - `/join` — Interactive Member vs. Affiliate Path Selector & 48-Hour Pastoral Onboarding Form
  - `/resources` (`/extras`) — Filterable Ministry Ecosystem Hub with zero dead links
  - `/contact` — Department-routed Contact & Confidential Prayer Request Desk

## Getting Started

```bash
npm install
npm run dev
```
